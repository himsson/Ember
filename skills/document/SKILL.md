---
name: document
title: Text or document
description: Write a letter, article, resume, guide or other text and save it to a file
---
Steps:
1. If something essential is unknown (who the text is for, the key facts), ask_user one short question with all of it. Do not invent names, dates or numbers.
2. Write the text and save it with write_file as a .md file (or .txt if the user wants plain text). Give the file a clear name, like letter-to-landlord.md.
3. Style: the language of the user, short paragraphs, concrete words, no filler phrases. A letter starts with a greeting and ends with a signature line.
4. finish: show the full text in "text" as well, and name the file where it is saved.
